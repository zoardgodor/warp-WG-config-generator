Privacy Policy

How this unofficial WARP WireGuard configuration generator handles data.

Last updated: October 29, 2026

1. About this tool

This is an unofficial, third-party tool. It is not operated, endorsed, or maintained by Cloudflare. It generates a WireGuard configuration using a registration request to Cloudflare's service.

2. Data processed by this website

When you generate a configuration, this website sends the following information from your browser to its hosting server:

  • Your WireGuard public key.
  • The device type, device model, and locale entered in the form.
  • Technical request information that the hosting server receives, which may include your IP address, request time, requested URL, and browser or user-agent information.

The hosting server forwards registration data to Cloudflare's registration endpoint and returns the necessary response fields to your browser.

3. Private keys and configuration files

The WireGuard key pair is generated in your browser. The private key, complete configuration text, and QR code are created locally by the website's JavaScript. The current application code does not intentionally send the private key or the complete configuration to the hosting server.

The generated configuration remains in your browser while the page is open. The website code does not intentionally save it to the hosting server. If you download, copy, or import the configuration, it will be handled by the destination you choose.

This protection depends on the JavaScript delivered to your browser being trustworthy. A compromised or modified website script could behave differently.

4. Hosting provider

This website is hosted by InfinityFree. The hosting provider can access the website's server-side files and process requests received by its servers. Its systems may record technical request information in server logs. The exact information retained, retention periods, and access practices are determined by the hosting provider's own policies and systems.

For more information, see the InfinityFree website and its applicable privacy information.

5. Cloudflare

Cloudflare receives registration information forwarded by this website, including your public key and the device type, model, and locale fields. Cloudflare also processes the connection made by the hosting server to its registration endpoint.

After you import and use the generated configuration, traffic routed through WARP is subject to Cloudflare's services and applicable policies. Read Cloudflare's WARP Privacy information and Application Terms of Service.

6. Third-party scripts

This website loads TweetNaCl and QRCode.js from cdnjs.cloudflare.com. When your browser requests these scripts, the CDN provider may receive technical connection information such as your IP address and browser details. The scripts run in the context of this website, so using external scripts is a security consideration.

7. Cookies, analytics, and storage

The current application code does not intentionally set cookies, use analytics, or store generated configurations on its own server. The hosting provider and third-party script provider may process technical data as described above.

8. Security and limitations

No website can guarantee absolute security. The hosting provider can access server-side code, and a malicious modification to the website's JavaScript could potentially access data handled in the browser. Do not use this tool if you cannot trust the website and its hosting environment.

Keep your generated configuration private. Anyone who obtains your configuration may be able to use its private key.

9. Changes

This policy may be updated if the website's functionality or data handling changes. The date at the top indicates the latest stated update.
